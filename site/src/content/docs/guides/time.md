---
title: 转换时间与时区
description: 转换 Unix 时间戳和常见日期字符串并查看多个时区。
---

## 支持的输入

`leo time` 接受 Unix 秒、Unix 毫秒和常见日期时间字符串。不传值时使用当前时间。

```bash
leo time
leo time 1783512043
leo time 1783512043000
leo time "(2026-07-08 20:00:43)"
```

纯数字达到 13 位时按毫秒解析，否则按秒解析。日期支持 `-` 或 `/` 分隔、可选秒数、RFC 3339 和带显式 offset 的形式。

## 输入与输出时区

`--from` 控制没有显式时区的日期字符串所使用的输入时区，`--to` 控制主要输出时区。两者都支持 UTC offset 或 IANA 名称，默认值均为 `+8`：

```bash
leo time "2026-08-06 22:26:09" --from -4
leo time 1783512043 --to +9
leo time "2026-07-08 20:00:43" --to Asia/Tokyo
```

第一个示例将 UTC-4 的日期解析为同一时刻在 UTC+8 的 `2026-08-07 10:26:09`。Unix 时间戳和自带时区的日期不受 `--from` 影响。配置中的 `time.zones` 会追加常用时区行；与主要输出相同的时区不会重复打印。
